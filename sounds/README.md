# Game sounds

Short 16-bit mono WAV effects used by the game:

- `walk.wav` — repeated footsteps while Karl moves
- `sleep.wav` — resting at the hostel or a home
- `work.wav` — starting a job shift
- `door_open.wav` — entering a building or clicking a destination
- `eat_drink.wav` — buying food, getting soup, or visiting Apotekergården
- `study.wav` — studying at Skole or Universitetet i Agder

The files are lightweight synthesized placeholders so the repository stays self-contained. Replace any `.wav` file with a longer effect of the same name to change the sound without code changes.
